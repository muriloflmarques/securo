# Docker, how to run

docker compose -f docker-compose.prod.yml up -d --force-recreate frontend

--Generate Database backup
docker exec securo-db-1 pg_restore -l /tmp/2026-10-05_securo_backup.dump

--Verify the dump properly on Windows
docker exec securo-db-1 pg_restore -l /tmp/securo_backup.dump

--Copy the valid dump out of Docker
docker cp securo-db-1:/tmp/securo_backup.dump .\2026-10-05_securo_backup_02.dump

Don't forget to merge from upstream on main branc

-----------------------------------------------------------------------
Once on Linux, navigate to "repo/securo" and then run
	git pull

Now it's necessary to build the image again without cache
	docker compose build --no-cache frontend
ou
	docker compose build --no-cache

Apply migrations using the updated backend image	
	docker compose run --rm backend alembic upgrade head

Then, recreate the running container
	docker compose up --detach --no-deps frontend
ou
	docker compose up --detach --no-deps

Verify the database revision
	docker compose exec backend alembic current

Refresh the browser
